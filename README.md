# 🧑‍💼 HR Data Analytics Project (MySQL + Power BI)

This project focuses on analyzing HR data using **MySQL** for data querying and **Power BI** for visualization. It provides insights into workforce demographics, work preferences, and departmental statistics based on a company's employee data.

## 📁 Repository Contents

- HR_Dashboard.pdf: Final Power BI dashboard export  
- HR_Data.csv / HR_Data.xlsx: Raw dataset used for analysis  
- SQL_Queries.sql: List of all MySQL queries used for data analysis  
- Power BI visualizations (PDF + PBIX if applicable)  

## 🔍 Key Questions Answered

1. Gender Breakdown – What is the gender distribution of employees in the company?  
2. Race Breakdown – What is the racial/ethnic composition of the workforce?  
3. Age Distribution – What is the age spread of employees across the company?  
4. Location Preference – How many employees work at HQ vs remote?  
5. Tenure Distribution by Department – What is the average tenure per department?  
6. Department-wise employee count  
7. Average age and tenure by role  
8. Attrition trends  
9. Recruitment pipeline metrics (if applicable)

## 📌 Tools Used

- MySQL – Data querying and preprocessing  
- Power BI – Dashboard design and visualization  
- Excel/CSV – Raw data input
